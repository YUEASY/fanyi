# Domain Docs

This is a single-context repository.

Before working on the codebase:

- Read the root `CONTEXT.md`.
- Read applicable ADRs under `docs/adr/` when that directory exists.
- Use the canonical terms defined in `CONTEXT.md`.
- Surface conflicts with an existing ADR instead of silently overriding it.
- Missing domain documents do not block work; create them lazily through the domain-modeling workflow.
